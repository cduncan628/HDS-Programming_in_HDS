# Predicting Phase 3 Clinical Trial Success: Exploratory Data Analysis

## Project Overview
This project explores a dataset of Phase 3 clinical trials to get ready for a
binary classification model that predicts whether a trial will meet its primary endpoint.

## Dataset
- **Name:** Clinical Trial Phase 3 Success
- **Source:** (https://www.kaggle.com/datasets/sergionefedov/what-predicts-a-phase-3-trials-success)
- **Size:** 42,000 rows, 17 columns (1 ID, 15 predictors, 1 target)
- **Target:** `trial_success` (1 = success, 0 = failure)
- See `data/data_dictionary_clinical_trial.csv` for variable descriptions.

## How to Run
1. Open `Dataset_Selection _and_Final_Project_Planning_Lab.ipynb` in Google Colab (click the file on GitHub, then
   "Open in Colab", or go to File → Open notebook → GitHub in Colab).
2. Click **Runtime → Run all**.
3. The data loads automatically from this repository. No uploads are needed. (unless you decide to import the dataset directly into Google Colab and run)

## Requirements
Python 3, pandas, numpy, matplotlib, seaborn (all pre-installed in Google Colab).

## Notebook Contents
1. Data selection and justification
2. Data import and structure
3. Target variable and predictor descriptions
4. Descriptive statistics
5. Exploratory visualizations
6. Data quality assessment
7. Preprocessing plan and potential challenges
8. Project plan (prediction problem and evaluation metric)
